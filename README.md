# Application 07: Text-to-Speech Converter

A browser-based text-to-speech converter using the native SpeechSynthesis API.

## Features
- **Speech Synthesis:** Speaks written text aloud using natural system voices.
- **Voice Selection:** Dynamically loads and selects from available operating system voices (e.g. Windows David, Zira, Mark).
- **Speed (Rate) and Pitch Controls:** Sliders to adjust speaking speed from 0.5x to 2.0x and pitch from 0.5 to 2.0.
- **Full Playback Controls:** Speak, Pause, Resume, and Stop buttons.
- **Empty Input Handling:** Validates text before attempting playback.
- **100% Offline:** Operates entirely locally on your machine with zero external network calls.

## Technologies
- HTML5
- CSS3
- JavaScript (Web Speech Synthesis API)

## How to Run
Double-click `RUN.bat` or open `index.html` directly in any web browser.
